# Finan — Financial Navigation and Analysis

A full stack web application for personal finance control, currently in development. The platform centralizes financial management in one place — from daily expenses to investments and goals — with a clean, modern dashboard connected to a real API.

---

## Tech Stack

### Frontend
- **React** with Vite
- **Tailwind CSS** for styling
- **React Router DOM** for client-side navigation
- **Recharts** for data visualization
- **Framer Motion** for UI animations

### Backend
- **Node.js** with **Express** for the RESTful API
- **MySQL** for data persistence
- Layered architecture with separated **controllers** and **routes**

---

## Features

- Dashboard with real-time balance, income, expenses and goals
- Debt tracking and management
- Investment control
- Financial goals with progress tracking
- Database modeled with 15 tables covering all financial entities
