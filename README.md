# Finan — Financial Navigation and Analysis

A full-stack web application for personal finance management, currently in development. Finan centralizes financial management in one place, covering daily expenses, income, debts, investments, and financial goals through a clean and modern interface connected to a RESTful API.

---

## Tech Stack

### Frontend
- **React** with Vite
- **Tailwind CSS** for styling
- **React Router DOM** for client-side navigation
- **Recharts** for data visualization
- **Framer Motion** for UI animations

### Backend
- **Node.js** with **Express** for the RESTful API
- **MySQL** for data persistence
- Layered architecture with separated **controllers** and **routes**

---

## Features

- Dashboard with real-time balance, income, expenses, and financial goals
- Debt tracking and management
- Investment management
- Financial goals with progress tracking
- Financial assistant
- Database modeled with 15 tables covering the application's financial entities
